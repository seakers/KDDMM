BIASED SAMPLING FUNCTION INDEX COMPUTATION FOR ASSIGNING PROBLEM:
The impact indices for the instrument count biased sampling function are computed using the initial population for the efficacy study runs.

UPDATED DATA:
After publishing of the paper, a bug in the computation of the metamaterial soft constraint indices was found (instead of using the repeatable connectivity array, the full connectivity array was used).
After this issue was resolved, the metrics were recomputed and the updated indices are stored here. 
There is a very small change in the screening study results for the metamaterial soft constraints but there is no change in the final conclusions of the paper.
The updated code has been pushed to the github repo.
